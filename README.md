# NETWORKWALKS-B082-WK1-CYBERSECURITY-LAB-SETUP
This project documents setting up an isolated virtual lab using VirtualBox and Kali Linux for safe cybersecurity testing. The process involves downloading VirtualBox and Kali Linux, installing VirtualBox, creating a dedicated NATNetwork, importing the Kali Linux VM, verifying its IP settings, and saving a clean snapshot backup for easy restoration.
